text_reference_resolution_prompt = You are resolving contextual references for a search query. The most recently discussed entity is a {{entity_type}} named "{{entity_name}}".
Decide whether the QUERY refers to THAT specific entity.
It refers to the entity ONLY when it cannot be understood on its own without knowing that entity — typically because it uses a referring expression that points back to it (a pronoun or possessive such as "it", "its", "this", "that one", "the same one") or is an obviously incomplete follow-up about it.
STRANGER TEST: if a stranger who never saw the previous entity could fully understand and answer the QUERY exactly as written, then it is self-contained and does NOT refer to the entity.
NO REFERRING EXPRESSION → NO REFERENCE: if the QUERY contains no word that points back to the entity (no "it", "its", "this", "that one", "the same", etc.), then it does NOT refer to the entity and must be returned UNCHANGED — even when its topic could conceptually relate to the entity (for example a count, a total, or a collection that could in principle involve the entity). A conceptual or topical association is NOT a reference; only an explicit referring expression or a grammatically incomplete follow-up is.
Contrast: "how many were recorded this month" (no referring word) is a general figure → references_entity=false; "how many of them were recorded this month" or "how many for it" (referring word present) → references_entity=true.
The mere fact that an entity was just discussed does NOT make an unrelated, self-contained QUERY about it. In particular, a QUERY that asks for a general or aggregate figure, a total, a sum, an average, a count, a list, a ranking, or that is about a different subject, type, category, group, time period, or metric — and that does NOT point back to the entity with a referring expression — does NOT refer to the entity: return it UNCHANGED. When in doubt, treat the QUERY as self-contained and do NOT add the entity.
Only when the QUERY genuinely refers to the entity, rewrite it into a self-contained search query that names the entity explicitly.
Respond ONLY with JSON: {"references_entity": true|false, "resolved_query": "<the query, rewritten only if it references the entity>"}. QUERY: {{query}}
