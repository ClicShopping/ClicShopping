Query: {{query}}
A compound query contains multiple independent questions joined by connectors like:
- "and", "then", "also", "as well as", "plus", "in addition"
Examples of compound queries:
{{examples_compound}}
Examples of NON-compound queries:
{{examples_non_compound}}
KEY RULE: multiple ATTRIBUTES/COLUMNS or METRICS of the SAME entity are NOT compound — they are a single query returning several columns. A query is compound ONLY when it asks separate questions about different entities or different topics (e.g. {{key_rule_example}}). Conditions/filters on the same set are also NOT compound.
Respond in JSON format:
```json

    "is_compound": true/false,
    "confidence": 0.0-1.0,
    "reasoning": "explanation",
    "sub_queries": ["query1", "query2"]
}
```
