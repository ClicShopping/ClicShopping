text_info_order_total_sequence = Les modules de total sont calculés dans une SÉQUENCE, et cette séquence a une valeur réglementaire : la base (sous-total), puis les réductions accordées sur la vente, puis les frais qui entrent dans la base taxable (port, manutention), puis la taxe, puis les frais hors base taxable, puis le total général, toujours en dernier. La plateforme place désormais chaque module à son rang d'elle-même : un module déclare son rôle fiscal, et un module qui n'en déclare aucun est refusé à l'installation, avec un message qui le dit.<br />Deux ordres coexistent et ce ne sont PAS les mêmes : le CALCUL suit les rangs ci-dessus, tandis que l'ordre de tri ci-dessous ne commande que l'ordre d'IMPRESSION des lignes sur la facture. Le modifier reste à votre main et ne change rien au calcul.<br />Une chaîne installée par une version antérieure conserve l'ordre qui lui avait été donné. Si une facture montre une réduction après la taxe, ou une ligne que le total général ne contient pas, désinstallez ce module puis réinstallez-le : il sera placé à son rang. La désinstallation efface aussi les réglages propres à ce module, notez-les avant.
text_warning_order_total_misplaced = Ces modules installés sont calculés à un endroit que la séquence n'autorise pas, les factures de cette boutique peuvent donc être fausses : {{modules}}.
