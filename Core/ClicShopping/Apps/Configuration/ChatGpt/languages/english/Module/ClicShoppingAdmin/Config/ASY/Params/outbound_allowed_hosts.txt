cfg_chatgpt_outbound_allowed_hosts_title = Allowed outbound hosts (LLM, embeddings, web search)
cfg_chatgpt_outbound_allowed_hosts_description = Used only when the policy above is set to Allowlist. List here, separated by commas, every service the AI layer is allowed to call. LLM providers, for chat and generation, as configured in the model catalogue: api.openai.com, api.anthropic.com, api.mistral.ai, generativelanguage.googleapis.com for Gemini. Embeddings, which reach two destinations only, whichever of the seven models you selected in RAG / Default embedding model: api.openai.com for the OpenAI Large and Medium models, api.voyageai.com for the three Voyage 3 models. Web search: serpapi.com. Self-hosted models on this machine or this LAN need no entry, the loopback and private ranges are not filtered here. An entry also covers its subdomains. A service you forget is blocked and the call fails with an explicit message, so list only the ones you actually configured. Example: api.openai.com, api.voyageai.com, serpapi.com
