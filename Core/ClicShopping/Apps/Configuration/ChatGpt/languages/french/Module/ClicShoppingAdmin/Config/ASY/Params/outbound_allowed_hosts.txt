cfg_chatgpt_outbound_allowed_hosts_title = Hôtes sortants autorisés (LLM, embeddings, recherche web)
cfg_chatgpt_outbound_allowed_hosts_description = Utilisé uniquement lorsque la politique ci-dessus est en Liste blanche. Listez ici, séparés par des virgules, tous les services que la couche IA a le droit d'appeler. Fournisseurs de LLM, pour le chat et la génération, selon le catalogue de modèles configuré : api.openai.com, api.anthropic.com, api.mistral.ai, generativelanguage.googleapis.com pour Gemini. Embeddings, qui ne joignent que deux destinations quel que soit le modèle choisi parmi les sept de RAG / Modèle d'embedding par défaut : api.openai.com pour les modèles OpenAI Large et Medium, api.voyageai.com pour les trois modèles Voyage 3. Recherche web : serpapi.com. Les modèles auto-hébergés sur cette machine ou ce réseau ne demandent aucune entrée, la boucle locale et les plages privées ne sont pas filtrées ici. Une entrée couvre aussi ses sous-domaines. Un service oublié est bloqué et l'appel échoue avec un message explicite : ne listez que ceux que vous avez réellement configurés. Exemple : api.openai.com, api.voyageai.com, serpapi.com
